# Screenshots and clips to capture

Keep each file under 1 MB, PNG or JPG preferred, GIF only where motion is the point. Before saving, check that no desktop, notification, account name or overlay with personal data is visible. Then remove the comment marks around the matching image tag in the README.

| File | What to show | How |
|---|---|---|
| `before-after-wall.png` | Two shots side by side from the same wall and camera angle: Coen crouched (vanilla), Coen upright (mod on). | Stand on a wall, press the toggle key (default `F7`) to switch between both, take one screenshot of each and join them. |
| `wall-walk.gif` | 8 seconds: walk along a wall, around a corner, then step off. The pose never snaps. | Mod on. |
| `config.png` | `config.ini` open in a text editor, showing the four keys. | Crop to the editor window. |
| `log-wolf-repair.png` | The log lines of one wolf repair (they start with `wolf repair:`). | Set `Logging = 1`, do wolf Haste then Shadowstep onto a wall, leave the wall, open `UprightWallStance.log`. |
